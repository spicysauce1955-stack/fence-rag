# Amendments to the frozen contract

Empty is the correct state. An amendment lands here as `NNN-short-slug.md` and
**governs nothing until ratified** — see [`../AMENDING.md`](../AMENDING.md) for the
four admissible triggers and the five steps.

If you are changing a BINDING item in `contract.md` and there is no file here for
it, stop: that is the exact failure the freeze exists to prevent.
