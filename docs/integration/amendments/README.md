# Amendments to the frozen contract

Empty is the correct state. An amendment lands here as `NNN-short-slug.md` and
**governs nothing until ratified** — see [`../AMENDING.md`](../AMENDING.md) for the
four admissible triggers and the five steps.

If you are changing a BINDING item in `contract.md` and there is no file here for
it, stop: that is the exact failure the freeze exists to prevent.

[`CANDIDATES.md`](CANDIDATES.md) is the waiting room. `AMENDING.md` §4 cuts a
version **when a batch is ready** — only a trigger-A falsification or a trigger-B
blocker forces a cut on its own, and everything else waits. Items wait there so
that waiting does not turn into forgetting. Nothing in it is filed and nothing in
it governs anything.

Its origin copy is `fence-rag/docs/integration/amendments/CANDIDATES.md`; both sides
write there, and every other copy is a mirror to be re-copied rather than edited.
Unlike `conversation.md`, that file is not append-only and nothing in it marks whose
copy is current, so two writers silently diverged the first day there were two
(`conversation.md` T50 §2). This rule is not an amendment and needs no ratification —
it keeps two mirrors of a working document in step and changes nothing that crosses
the boundary, which `AMENDING.md` §2's exclusions already cover.
